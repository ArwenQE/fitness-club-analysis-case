# fitness-club-analysis-case

Мини‑проект по анализу данных фитнес‑клуба: активность, выручка, удержание.

## Файлы

- `01_fitness-client-activity.ipynb` — анализ активности и вовлечённости клиентов (посещаемость, динамика по месяцам, сегментация по возрасту и городам).
- `02_fitness-client-revenue-retention.ipynb` — расчёт ключевых бизнес‑метрик: когортный анализ, удержание (retention), доля повторных клиентов и вклад сегментов в выручку.
- `data/` — исходные данные в формате CSV.

## Стек технологий

Python, Pandas (обработка и агрегация данных), Matplotlib/Seaborn (визуализация), Jupyter Notebook.

## Ключевые результаты

- Выявлены пики посещаемости и наиболее активные сегменты аудитории.
- Построены когорты и рассчитан уровень удержания клиентов на горизонте 3–6 месяцев.
- Определён вклад разных групп клиентов в общую выручку клуба.
